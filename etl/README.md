# Near Me ETL

Standalone Python scripts that build the dataset behind `/near-me`, `/map`,
`/trt/{city}` and `/glp1/{city}`. Scope: Dallas–Fort Worth. Businesses and
buildings only; see `../docs/near-me/methodology.md` for the rules.

```
pip install -r requirements.txt
python build_zips.py            # once; writes data/dfw_zips.csv (zip centroids)
python fetch_npi.py             # NPPES: TRT / metabolic clinics
python fetch_open_payments.py   # CMS Open Payments: GLP-1 prescriber proxy
python fetch_pharmacies.py      # TSBP + FDA 503B lists (data/*.csv) + OSM candidates
python fetch_gyms.py            # OSM (Overpass/Nominatim) + optional Google Places
python geocode.py              # street-level coordinates via Nominatim (slow, cached)
python aggregate_h3.py          # -> public/data/nearme/*.geojson, src/data/nearme/*.json
python snapshot.py              # quarterly time series (etl/snapshots/)
python moderate.py list|approve|reject|export   # submissions queue
```

Env (all optional): `GOOGLE_PLACES_KEY`, `OVERPASS_URL`, `DATABASE_URL`,
`MODERATOR`.

Operator-maintained inputs in `data/`:

| file | from |
| --- | --- |
| `dfw_zips.csv` | generated by `build_zips.py` |
| `tsbp_compounders.csv` | Texas State Board of Pharmacy license search, compounding pharmacies (`name,address,city,zip,license,sterile`) |
| `fda_503b.csv` | FDA registered outsourcing facilities, TX rows (`name,address,city,state,zip,fei`) |
| `price_reports.csv` | written by `moderate.py export` |

Outputs in `out/` are gitignored except nothing: the committed artifacts are
the exported JSON/GeoJSON the site imports, so a deploy never depends on the
upstream APIs being up.

### TSBP export (manual)

The Texas State Board of Pharmacy search (<https://www.pharmacy.texas.gov/dbsearch/phy_search.asp>)
renders through a browser-only grid and answers automated requests with an
empty set, so the compounding list is an operator export: search by county
(Dallas, Tarrant, Collin, Denton), use the grid's CSV button, keep rows whose
detail page lists sterile or non-sterile compounding, and paste them into
`data/tsbp_compounders.csv` with the columns above. The FDA 503B registry is
scraped live.
